# Ankerstone 1.2.0 for Minecraft 26.2

- Single and Wide particle counts can be adjusted separately. Set either to 0 to turn its particles off. The defaults are unchanged.
- Settings are saved on the client and still apply without Mod Menu. Chunk loading is unchanged.
