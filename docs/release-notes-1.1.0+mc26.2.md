# Ankerstone 1.1.0 for Minecraft 26.2

- Added a world-saved limit on active Ankerstones across all dimensions. The default is unlimited, and lowering the limit leaves existing Ankerstones active.
- Added `/ankerstone list` to find active Ankerstones by dimension, coordinates, and mode. Operators can click a list entry to visit it in Spectator mode.
- Startup now checks restored Ankerstones, removes stale chunk tickets, and corrects modes that no longer match redstone power.
